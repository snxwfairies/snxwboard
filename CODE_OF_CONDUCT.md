# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, critique code and not people, and do not harass anyone. Maintainers may
remove comments, commits or contributors that break these rules.

To report a problem privately, use **Security → Report a vulnerability** on this repository and say it is a
conduct report, or message a maintainer directly. Reports are kept confidential.
